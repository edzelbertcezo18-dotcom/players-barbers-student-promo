# PLAYERS BARBERS — Long-Term Student Promo

Updated project direction:
- No fixed promo dates / year-round student program
- No NFC
- No digital loyalty tracking
- Physical loyalty card with manual stamps
- ₱200 student package
- Haircut + free shampoo + loyalty card + 1 stamp
- Suggested reward: 5 qualifying stamps = free haircut
- Student ID verification required

## Run locally
1. Install Node.js.
2. Open Command Prompt in this folder.
3. Run `node server.js`.
4. Open `http://localhost:3000`.

## Important
The included add-on is free shampoo.


## Location
2nd floor, MAGIC MALL ANNEX URDANETA, PANGASINAN


## Student verification flow
Students select their school, follow the PLAYERS BARBERS Facebook page, return to the site, and press the code button. A 6-character promo code is generated and shown to the student. Staff manually confirms the code together with the student's ID before approving the promo.

Note: this prototype does not automatically verify a Facebook follow. Staff confirmation is required.
